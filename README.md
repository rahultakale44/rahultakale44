##  Systems I've Built

###  ForgeDB — Lightweight Database Engine

A **C++20 database engine built from scratch**, focused on understanding database internals rather than using an existing database abstraction.

**Core engineering:**

* 4KB page-based storage layer
* Persistent Disk Manager
* Page serialization & deserialization
* Checksum-based integrity validation
* Buffer Pool Manager
* LRU page replacement
* Pin/unpin & dirty-page management
* B+ Tree indexing
* GoogleTest-based testing
* CMake build system
* GitHub Actions CI

> Building a database from the storage layer upward to understand how real database systems work.

---

###  Nexora — Semantic Knowledge Orchestration Platform

An enterprise-oriented semantic knowledge system combining multiple retrieval and reasoning strategies.

**Architecture includes:**

* Hybrid vector + graph retrieval
* Knowledge graphs with Neo4j
* Vector search with Qdrant
* PostgreSQL-backed services
* Redis semantic caching
* Adaptive LLM routing
* Self-correcting retrieval
* LangGraph orchestration
* FastAPI backend
* React frontend
* Dockerized infrastructure
* Retrieval & latency benchmarking

> **Goal:** make enterprise knowledge retrieval faster, more grounded and measurable.

---

###  Probabilistic Electricity Price Forecasting

A forecasting system designed for electricity-market price prediction using Transformer-based architectures.

**Highlights:**

* Multi-horizon forecasting
* P10 / P50 / P90 probabilistic predictions
* Leakage-free feature engineering
* Historical + future-known features
* Multi-head attention
* WMAPE-based evaluation
* Production-oriented FastAPI serving
* PostgreSQL data layer

###  Media Revenue Forecasting Platform

**Engineering highlights:**

* P10 / P50 / P90 forecasts

* FastAPI backend
